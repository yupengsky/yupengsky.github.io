# Yupeng Wang Personal Homepage

This is a zero-build GitHub Pages homepage for 2027 graduate applications.

## Structure

- `index.html` is the full homepage.
- `styles.css` contains all styling.
- `assets/img/` stores compressed photos, PDF slide exports, posters, and GIF previews.
- `assets/video/` stores H.264 web videos.
- `assets/docs/wang-yupeng-cv.pdf` is the public CV download.

## Local Preview

Open `index.html` directly in a browser. No build step is required.

## Design References

The information architecture follows common patterns from academic homepage templates:

- al-folio: clean academic homepage with projects and community examples.
- academicpages: GitHub Pages and Markdown-based academic portfolio structure.
- AcadHomepage: responsive academic homepage focused on simple presentation.
